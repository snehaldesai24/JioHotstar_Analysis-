# 📊 Hotstar Data Analysis

## 🧠 Overview
This project explores and analyzes Hotstar’s dataset to uncover key insights about user engagement, content preferences, and performance trends across genres, languages, and time periods.  
The analysis is performed using Python in Jupyter Notebook, leveraging data analytics and visualization techniques to transform raw data into meaningful patterns and actionable findings.

---

## 🎯 Objectives
- To understand user engagement patterns on the Hotstar platform.  
- To analyze content performance based on genres, ratings, and viewership.  
- To identify trends in user preferences and regional viewing habits.  
- To visualize insights that can help improve platform strategy and recommendations.

---

## 🧰 Technologies Used
- **Python** – Core programming language for analysis  
- **Pandas** – Data manipulation and cleaning  
- **NumPy** – Numerical operations and computations  
- **Matplotlib & Seaborn** – Data visualization  
- **Jupyter Notebook** – Interactive analysis environment  

---

## ⚙️ Project Workflow
1. **Data Loading & Inspection**  
   - Loaded dataset into Pandas DataFrame.  
   - Performed initial exploration and checked for null/missing values.

2. **Data Cleaning**  
   - Removed duplicates and handled missing data.  
   - Converted data types for consistency.  

3. **Exploratory Data Analysis (EDA)**  
   - Distribution analysis of ratings, content type, and release years.  
   - Identified top-performing genres and languages.  
   - Compared user preferences between movies and shows.  
   - Created visual insights using bar charts, pie charts, and heatmaps.

4. **Visualization**  
   - Graphical representation of key metrics using Matplotlib and Seaborn.  
   - Highlighted viewership patterns and correlations between features.  

---

## 📈 Key Insights
- Certain genres like **Drama** and **Action** dominate viewership trends.  
- The majority of Hotstar users prefer **Hindi and English** content.  
- A sharp rise in **original series** and regional content engagement is visible.  
- High-rated content often belongs to specific genres or release periods.
